# 다음 작업: 원자재·거시지표 대시보드 (⑤)

> 상태: 2026.11.2 `macro_dash/` 로 구현 완료 (README 참고). 통계표·항목명은 실제 ECOS 키로 `--check` 확인 필요.

2026.7 대화 "국내 경제지표 기반 원자재 재고 관리 시스템"과 8월 대화 "보고 형식을 의사결정 중심으로 개선하기"에서 설계만 해둔 것을 구현함.

## 목표
한국은행 ECOS API로 거시지표를 받아 **의사결정 지원용 대시보드(HTML 한 파일)** 생성. 가격 예측이 아니라 국면 판정·민감도 표시.

## 데이터 (ECOS 통계표)
- 기준금리, 국고채 3년, 회사채 AA- 3년
- 원/달러·원/유로·원/엔 환율 (월평균)
- 수입물가지수(원재료), 생산자물가지수(1차금속·화학·전기전자)
- 소비자물가, 제조업 BSI
- 선택: 구리·알루미늄·니켈(LME, 외부 CSV 업로드), 유가(두바이)

## 화면
1. 상단 국면 신호등: 금리 방향 / 환율 추세 / 원자재 국면 (상승·안정·하락) — 3개월·12개월 이동평균 비교
2. 지표별 추이 차트 (단일 축, 36개월), 전월·전년 대비 증감
3. 민감도 시트: "환율 10원 ↑ → 원가 X억" 계수 입력 → 월별 원가 영향 추정 (사용자가 계수 입력, 추정 표시)
4. 권장 재고 커버리지(주) — 변동성 구간별 룰 테이블 (사용자 편집)
5. 엑셀 내보내기 (맑은 고딕), 데이터 CSV 캐시

## 구현 지침
- 이 저장소의 `dart_report/client.py` 패턴 그대로: `.env` 의 `ECOS_API_KEY`, `cache/` 캐시, `--fixtures` 오프라인 모드, 테스트 픽스처
- 패키지명 `macro_dash/`, 실행 `python -m macro_dash --out out/`
- 글꼴: HTML Pretendard, 엑셀 맑은 고딕. 글자 크기 정수 pt. 개조식 문체
- 차트 색 팔레트: NAVY #00338D · LBLUE #0091DA · ORG #ED7D31 · RED #C00000 (consulting-pptx 저장소와 동일)
- 추정치는 반드시 "추정" 표기, 출처·기준일 명시
